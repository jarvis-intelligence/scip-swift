<objective>
Replace the referenced-but-undefined heuristic for external_symbols with authoritative SymbolLocation.isSystem classification (META-04), and create a new SignatureMapping pure-function mapper that reconstructs minimal Swift signatures from Symbol.kind/name for hover tooltips (META-05). This plan depends on Plan 01-01 because SCIPIndexBuilder is already modified there — this plan adds isSystem tracking and signature population to the same occurrence loop.

Purpose: The current heuristic misclassifies project-internal cross-module symbols as external, which would break multi-repo merge. The isSystem flag is compiler-authoritative and marks actual stdlib/framework occurrences. Signatures improve hover tooltips from bare names (current state) to useful declarations like "func greet(name:)".

Output: A new SignatureMapping mapper with tests, modified SCIPIndexBuilder with isSystem-based external classification, and extended integration test verifying external symbols are system-only.
</objective>
