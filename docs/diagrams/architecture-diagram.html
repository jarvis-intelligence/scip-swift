scip-swift / architecture

Swift repo → build → IndexStore → SCIP protobuf → index.scip

Pipeline

  • 01 · CLI — ScipSwiftCommand → IndexCommand
  • 02 · Build — detect, build with indexing on
  • 03 · Index — open IndexStoreDB, walk .swift
  • 04 · Map — occurrences → SCIP messages
  • 05 · Output — write index.scip

Design

  • Does not parse Swift — uses compiler IndexStore
  • 4 mappers are pure, stateless, exhaustive
  • Symbols use raw USRs — no demangling
  • Auto-detects swiftpm vs xcodebuild

Constraints

  • macOS-only (Xcode + libIndexStore + SDKs)
  • Swift toolchain pinned to 6.2.4
  • Occurrence ranges approximated
  • No call-role in SCIP spec
